## 启动

在**项目根目录**运行（脚本实际位于 `scripts/local/`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\local\启动本地.ps1
```

脚本会：

1. 如果 PostgreSQL 没启动，先用便携版启动
2. 如果 3000 端口没有服务，启动 Node 应用
3. 自动打开 http://127.0.0.1:3000

## 停止

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\local\停止本地.ps1
```

## 注意

- 这是本地开发部署，没有 HTTPS，不要直接暴露到公网。
- 如果换了电脑，需要重新准备 PostgreSQL 17 和 `app/node_modules`。
- 当前代码基于远程 `main` 分支（已包含注册/登录、邀请码绑定、多人组模型），不是最初 zip 里的固定双账号版本。
